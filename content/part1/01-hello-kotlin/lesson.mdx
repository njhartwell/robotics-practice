# Hello, Kotlin!

Welcome to your first Kotlin lesson! Kotlin is the language used by many FRC teams to program their robots. Let's start with the basics.

Every Kotlin program starts with a `main` function:

```kotlin
fun main() {
    println("Hello, World!")
}
```

The `println` function prints text to the console, followed by a new line.
