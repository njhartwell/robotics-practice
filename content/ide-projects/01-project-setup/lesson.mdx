# WPILib Project Structure

In this lesson, you'll set up a WPILib project in IntelliJ and understand the key files.

## Prerequisites

- IntelliJ IDEA installed
- WPILib VS Code extension installed (for project generation)

## Project Layout

A WPILib command-based project has this structure:

```
src/main/java/frc/robot/
├── Robot.kt           # Robot lifecycle (don't modify much)
├── RobotContainer.kt  # Wire subsystems to commands
├── Constants.kt       # Robot-wide constants
├── subsystems/        # Hardware abstractions
└── commands/          # Robot behaviors
```

## Tasks

Download the starter project and open it in IntelliJ. Explore the file structure and identify each file's role.

<Checklist>
- Downloaded and opened the starter project
- Identified Robot.kt and its lifecycle methods
- Found RobotContainer.kt and understand its role
- Located the subsystems and commands directories
</Checklist>
