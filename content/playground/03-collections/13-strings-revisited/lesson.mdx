# Strings Revisited

You have already used strings to store text like team names and messages. Now it is time to explore what else you can do with them. Strings have many built-in tools that make working with text easier.

## Strings Are Sequences of Characters

A string is made up of individual characters lined up in order. The string `"Tribots"` has 7 characters: T, r, i, b, o, t, s.

Each character has a position number called an **index**. Indexes start at 0, not 1.

```kotlin
fun main() {
    val team = "Tribots"
    println(team[0]) // T
    println(team[1]) // r
    println(team[6]) // s
}
```

The first character is at index 0. The last character is at index `length - 1`.

## Useful String Properties and Functions

### Length

The `.length` property tells you how many characters are in a string:

```kotlin
fun main() {
    val name = "Team 4215"
    println(name.length) // 9
}
```

### Uppercase and Lowercase

You can convert a string to all uppercase or all lowercase letters:

```kotlin
fun main() {
    val team = "Tribots"
    println(team.uppercase()) // TRIBOTS
    println(team.lowercase()) // tribots
}
```

The original string does not change. These functions give you a new string.

## Getting Part of a String

The `.substring()` function lets you grab a piece of a string. You give it a start index and an end index. The start is included, but the end is not:

```kotlin
fun main() {
    val label = "Motor-Left-Drive"
    println(label.substring(0, 5))  // Motor
    println(label.substring(6, 10)) // Left
}
```

You can also use `.substring(startIndex)` to get everything from that position to the end:

```kotlin
fun main() {
    val label = "Motor-Left-Drive"
    println(label.substring(11)) // Drive
}
```

## Splitting Strings Apart

The `.split()` function breaks a string into a list of smaller strings. You tell it what character or text to split on:

```kotlin
fun main() {
    val data = "Red,Blue,Red"
    val parts = data.split(",")
    println(parts[0]) // Red
    println(parts[1]) // Blue
    println(parts[2]) // Red
}
```

This is useful when you receive data in a format like `"100,200,150"` and need to work with each value separately.

## Trimming and Checking

### Trim

`.trim()` removes any spaces (or other whitespace) from the beginning and end of a string:

```kotlin
fun main() {
    val input = "  Team 4215  "
    println(input.trim()) // Team 4215
}
```

### StartsWith and EndsWith

These return `true` or `false`:

```kotlin
fun main() {
    val filename = "auto_routine.kt"
    println(filename.startsWith("auto"))  // true
    println(filename.endsWith(".kt"))     // true
    println(filename.endsWith(".java"))   // false
}
```

## String Templates with Expressions

You already know that `$variableName` puts a variable's value inside a string. When you need something more than a variable name, wrap it in curly braces `${}`:

```kotlin
fun main() {
    val scores = listOf(42, 55, 38)
    println("Total: ${scores[0] + scores[1] + scores[2]}")
    println("First score: ${scores[0]}")
}
```

Anything inside `${}` is evaluated as Kotlin code.

## Building Strings with Loops

You can build up a string one piece at a time using a `var` and a loop:

```kotlin
fun main() {
    var cheer = ""
    for (i in 1..3) {
        cheer = cheer + "Go Tribots! "
    }
    println(cheer.trim())
}
```

Output:
```
Go Tribots! Go Tribots! Go Tribots!
```

Each time through the loop, we add more text to the end of the string.
