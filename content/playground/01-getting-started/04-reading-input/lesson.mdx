# Working with Input Values

Programs become useful when they work with values from outside the program. A
console app might receive text typed by a person. An FRC robot receives joystick
positions, button presses, sensor readings, and messages from the Driver Station.

## Reading Text in a Console

Kotlin reads one line of typed console input with `readln()`:

```kotlin
fun main() {
    print("Enter your team number: ")
    val teamNumber = readln()
    println("Go team $teamNumber!")
}
```

When execution reaches `readln()`, the program pauses until the user enters a
line. The returned value is a `String`. Calling `readln()` again reads the next
line, so a program can collect several values:

```kotlin
fun main() {
    val driverName = readln()
    val robotName = readln()
    println("$driverName is driving $robotName")
}
```

Our browser playground cannot pause and wait for someone to type into an
interactive console. In this lesson, variables stand in for values that would
normally arrive from a person or robot device.

## Simulating an Input Value

Start by storing a sample input in a variable. The rest of the program uses the
variable without caring where its value originally came from:

```kotlin
fun main() {
    val driverName = "Alex" // imagine this came from the Driver Station
    println("Hello, $driverName!")
}
```

Later, when you learn functions, you will pass changing input values through
function parameters. For now, keeping the sample value in `main()` lets you
practice processing input with the variables and types you already know.

## Converting Text Input

Console input starts as text, even when the user types digits. Convert the text
before doing arithmetic:

```kotlin
fun main() {
    val inputText = "40" // imagine this came from readln()
    val joystickPercent = inputText.toInt()
    val doubled = joystickPercent * 2
    println(doubled)
}
```

Use `.toInt()` for whole numbers, `.toDouble()` for decimal numbers, and
`.toBooleanStrict()` for the exact text `"true"` or `"false"`. In a console app,
the direct version would look like `val teamNumber = readln().toInt()`.

These conversions expect valid text. Later, after learning about nullable
values, you will use helpers such as `toIntOrNull()` when bad input is possible.

## Why the Playground Uses Sample Values

The important skill is separating the value a program receives from the work it
does with that value. Sample variables make that idea visible without requiring
an interactive terminal.

## Combining Multiple Inputs

Real programs often combine several incoming values into one useful result. A
Driver Station display might show a driver's name, team number, sensor value,
and robot state in a single status message. Store each value separately, then
use a string template to make the output readable.
